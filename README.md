# Introduction

This repository contains source code for a website platorm dedicated to any type of community (community = group of people).  
Purpose of the platform is to provide:
- *optional participation*
- *unobstructed communication*
- *transparency*
- *confidentiality*
- *anonimity*
- *flexibility*
- *ease of use*

End goal is to allow every member of the community equal opportunity in a decision making process.

> [!NOTE]  
> Platform isn't dedicated to political parties **nor anyhow connected to the governments of particular region/state**. Platform authors strongly believe that "current" political systems are **outdated** and does not serve the purpose of the humanity anymore.

## Platform features

Platform provides following features:
- free registration
- community proposals suggestion
- proposal scrutinization section
- suggestion of temporal implementation groups
- selection of candidates
- browsing candidates biographies
- proposed suggestions voting system (based on majority voting principles)
- anonymous usage
- open source

## Technical details
Platform is written in `TypeScript` using `SvelteKit` framework. It uses [`bun package manager`](https://bun.sh/) to manage dependencies. Make sure you have `bun` installed on your machine before running the dev server.

Follow these steps to run the development version locally:

```bash
# to install needed dependencies
bun install

# to start the server and open the app in a new browser tab
bun run dev
```

To create **production** version of the platfrom, run:

```bash
bun run build
```

Icons and imagery provided by [SVG repo](https://www.svgrepo.com/).
